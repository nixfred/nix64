Troubleshooting

The window says offline

The shell's server is not running. Run nix64 again; nix64 doctor checks the engine, the browser and the agent.

Nothing types

Click the screen: the line under it says keyboard on the C64 when it has focus. F10 lets go.

The machine is slow or stuttering

The engine needs a steady CPU. The shell never slows it: reading the screen costs nothing. If you recorded a video or have many machines in the Hub, close some. The fps chip under the screen shows the real emulated frame rate (50 for PAL, about 60 for NTSC).

No agent

Settings > Agent shows what was found. On Omarchy Claude Code comes with the system; sign in once with claude in a terminal.

No sound

The engine plays through your normal audio. Check the machine file's [sound] section and that the volume is above 0. The interface sounds are separate (Settings > Sound).

A disk will not load

Type LOAD"$",8 then LIST to see what is on it. ?DEVICE NOT PRESENT means no disk in drive 8; ?FILE NOT FOUND means the name is wrong.
