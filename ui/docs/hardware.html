Real hardware

Nix64 can use real devices where the engine supports them. Devices (left rail) shows what is plugged in and what this build can do. Each device has a badge: verified (tested on that hardware, with date and model), untested (the path exists but has not been run against the real thing), experimental, or not in this build.

The package installs a udev rule so the logged-in user can open a ZoomFloppy without root. There is no root daemon and no privilege wall: you own the machine.
