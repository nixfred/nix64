The keyboard

The C64 keyboard is not a PC keyboard with different legends. Nix64 maps yours symbolically, like VICE's own keymap: what you type is what appears. ( is Shift+9 on a PC but Shift+8 on a C64, and Nix64 presses the right C64 keys for you.

Joystick

Ctrl+J (or "Keys as stick") turns the arrow keys and Space into a joystick in port 2. A gamepad is picked up automatically and also drives port 2. On a real C64, a joystick in port 2 shares wires with the keyboard, so a held stick can type stray characters: Nix64 keeps that authentic behaviour.

Pasting and the on-screen keyboard

Paste text with Ctrl+V while the screen has focus: it is typed through the real keyboard buffer. Characters the C64 cannot type are refused, not changed. On the on-screen keyboard SHIFT, C= and CTRL stay down until the next key.
