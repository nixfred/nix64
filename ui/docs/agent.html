The agent

Nix64 uses the agent already on your computer: Omarchy ships Claude Code; Codex, pi, opencode and Crush are found too. Settings > Agent chooses one, sets a model, and can point it at a model you run yourself (Ollama, LM Studio). Claude Code is the fully integrated one; the others run in a basic mode that has not been tested against Nix64.

Assist: it watches, and speaks up when you look stuck

Watching is free and local: simple rules over the machine's own screen and memory, no model, no network. It speaks only when something goes wrong: a command from another BASIC (SOUND, CLS, COLOR…), the same error again, an error left unanswered, a line typed and cleared twice. A card slides in beside the screen, never over it:

  • Do it for me: it types the C64 way on the real keyboard (for known cases it needs no model at all) and says what it did.
  • Guide me: the next key lights up on the on-screen keyboard and it checks each line. You type; nothing is done for you.
  • Not now: it waits longer next time. It starts eager and backs off. The Quiet switch in the top bar silences it entirely.

If you type fast and clean, nothing fires, so you never see a card.

Drive: you ask, it does it where you can watch

Write what you want in the prompt. The agent gets one tool: c64ctl, which reads the screen and presses keys and moves sticks through the machine's real input. It types at the speed you set (Settings > Agent). It cannot run anything else on your computer.

The feed beside the screen tags every step: ON C64 (done through the machine's own inputs, with the channel), HOST STEP (anything else: a refused request is shown too), AGENT (what it says), NOTE. A request that was refused is not shown as done.

STOP

The red STOP button (or Esc in the prompt) throws away everything queued, lets go of every key and stick, and ends the agent run, instantly, however much typing was waiting.

Whatever the C64 shows is data

Screens, disk directories and BBS banners can contain anything. The agent is told they are data, never instructions, and acts only on what you wrote.
