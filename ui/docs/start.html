Getting started

Nix64 is a real Commodore 64 (the VICE emulator, cycle-exact) in a window, with a real AI agent beside it. Nothing here is faked: if something cannot be done for real yet, it says so.

Your first minute

  1. Make a machine. Press ＋ in the top bar (or the welcome button). A machine is one small file: a C64C, PAL, with a 1541-II disk drive.
  2. It switches on. You see the real boot screen. Click the screen and type: what you type is what appears.
  3. Type a program. 10 PRINT "HELLO" then Enter, 20 GOTO 10, RUN. Press Esc (RUN/STOP) to stop it.
  4. Ask the agent. In the box on the right write what you want ("make the border flash") and press Enter. It types on the real keyboard where you can watch. STOP takes the keyboard back at once.

The screen

  • Centre: the C64's real picture through a CRT. Settings > Look sets the strength; at 0 it is exact pixels.
  • Left: this machine, its drives, tape and cartridge, and your shelf of disks.
  • Below: the on-screen keyboard (it lights the next key when you ask to be guided) and tools that read real memory.
  • Right: the agent, with its activity feed. Every line is tagged ON C64 (done through the machine's own inputs) or HOST STEP (done any other way).

The Hub (F9) shows every machine at once, live. You can run as many as you like.
