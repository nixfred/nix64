Machines and files

A machine is one declarative file that says exactly what the computer is: model, region, SID chip, drives, devices. Press Machine file to read or edit it; the comments in it are its documentation.

model  = "c64c"      # c64, c64c, c64old, c64gs
region = "pal"       # pal (50 Hz) or ntsc (60 Hz)
[sid]    model = "6581"
[drive.8] type = "1541-II"  mode = "image"
          image = "shelf:my-disk.d64"

Generations, like NixOS

Every time the file changes and you press Save and apply, Nix64 records a numbered generation. Any earlier one can be rolled back to, and the old file is put back exactly. Disks and cartridges named in the file are pinned by SHA-256 in a content-addressed store, so the same file is the same machine anywhere. A running machine keeps its generation until you power it off and on.

From the terminal

nix64 ls                 machines and which are on
nix64 new NAME           make one (--preset c64c-pal|breadbin-pal|c64c-ntsc|gs)
nix64 start NAME         switch on, no window needed
nix64 edit NAME          edit the file, record a generation
nix64 rollback NAME 2    put generation 2's file back
nix64 classic            the plain engine window, no shell

Machines run headless as small services of their own (systemctl --user status nix64-m-NAME), so closing the window does not stop them; open the window again and they are still running.

Freeze slots

The four Freeze buttons save the whole machine (CPU, RAM, chips, disks) as a VICE snapshot. Click a full slot to restore it; Shift+click to save over it.
