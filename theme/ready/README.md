# READY.

The Nix64 desktop theme for [Omarchy](https://github.com/basecamp/omarchy): the Commodore 64's own colours,
the light blue border and the deep blue screen, on a dark desktop.

The palette is the C64's (the Pepto measurements of the VIC-II colours), darkened so it works as a desktop:
text in the boot-screen lavender, accents in light blue, greens and yellows from the same sixteen colours.

## Install

```bash
nix64 theme install      # copies it to ~/.config/omarchy/themes/ready
omarchy theme set ready  # switch to it when you like
```
